# Design inspo

`library/<name>.md` holds 84 `DESIGN.md` style guides, each describing the look of a well-known
brand's website: colour palette and roles, typography, components, layout, depth, dos and don'ts,
responsive rules. `INDEX.md` has a one-line summary of each. They are the same files listed on
getdesign.md (source and update steps in `SOURCE.md`), kept here because that site may be blocked
by this environment's network policy.

## When the user needs a design

1. **Ask (or recall) the brief**: what the site is for, who visits it, any brands or sites they like.
2. **Shortlist from `INDEX.md`**: pick 3–5 styles whose *feel* fits the subject and audience, not
   just the same industry. If the user named a brand, include it. Read each shortlisted file whole.
3. **Offer the options together with the other skills' options** (Taste Skill's dealt directions,
   UI/UX Pro Max's recommendation), so the user compares everything side by side. Show each option as
   a quick mockup of the top of the page, labelled in plain words ("warm and minimal, inspired by
   Notion"), not design jargon. The user is new to design: explain choices simply.
4. **Let the user choose, ask for more, or mix** ("fonts from one, colours from another").
5. **Build from the chosen file**, using its palette roles, type scale, spacing, component rules
   and do's/don'ts as the system. Still run the other skills' quality checks (Taste Skill's
   inspector, UI/UX Pro Max's accessibility and UX guidelines).

## Inspiration, not imitation

These files are unofficial analyses of other companies' sites. The user's site must be its own:

- Never use the brand's name, logo, product names, slogans, imagery or exact layouts.
- Proprietary fonts named in a file (SF Pro, Airbnb Cereal, Kraken-Brand, NouvelR …) are not
  free: substitute a free Google Fonts lookalike, or a font the user has a licence for.
- Take the feel (mood, proportions, palette relationships, type character, spacing rhythm) and
  adapt colours and details so the result is not mistakable for the original brand.
